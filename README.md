## 자주 사용하는 단축키

| 단축키         | 설명                                   |
|-------------|--------------------------------------|
| `Ctrl + C`  | 현재 입력이나 클로드의 현재 생성 중인 아웃풋을 중단        |
| `Ctrl + D`  | 클로드 코드 세션 종료                         |
| `Ctrl + L`  | 클로드 코드와의 대화는 유지하며 사용자 대화창의 입력을 전부 삭제 |
| `Esc + Esc` | 직전 메시지로 회귀                           |
| `# [메시지]`   | `CLUADE.md`에 빠르게 기억해야할 요소를 추가        |
| `/ [명령어]`   | 슬래시 Command를 실행                      |

## 슬래시 명령어 목록 및 간단 설명

- `/model` : 모델 정보 조회 및 선택/전환을 합니다.
- `/compact` : 출력 형식을 간단 모드로 전환하거나 요약 출력을 요청합니다.
- `/config` : 현재 설정 확인 및 일시적 설정 오버라이드를 수행합니다.
- `/permissions` : 프로젝트·파일 접근 권한 상태를 확인하고 권한 관련 안내를 제공합니다.
- `/memory` : 메모리 파일(`./CLAUDE.md` 등) 조회·요약 및 관련 내용을 업데이트하는 제안 기능입니다.
- `/mcp` : MCP 서버 설정 확인·연결 테스트 및 도구 사용 안내를 제공합니다.
- `/doctor` : 프로젝트 문제 진단(의존성·설정·빌드 실패 등)과 해결 방법을 제안합니다.
- `/status` : 현재 세션·에이전트·자동 수정 모드 등의 상태를 요약합니다.
- `/cost` : 예상 호출/처리 비용 추정 및 비용 절감 제안을 제공합니다.
- `/ide` : IDE 관련 명령(열기·포커스·런 설정 등) 및 IDE 통합 도움말을 제공합니다.

## 메모리 파일 설명

### 프로젝트 메모리: `./CLAUDE.md`  
- 이 프로젝트 전용의 규칙, 컨벤션, 도메인 지식 등을 저장합니다.  
- 같은 저장소 안의 모든 세션에서 공통으로 참고됩니다.

### 로컬 프로젝트 메모리: `./claude.local.md`  
- 현재 개발 머신에서만 사용하는 프로젝트 전용 메모리입니다.  
- 개인적인 메모, 임시 규칙 등 저장소에 커밋하지 않을 정보를 적습니다.

### 사용자 메모리: `~/.claude/CLAUDE.md`  
- 특정 프로젝트와 상관없이, 사용자 전역에 적용되는 선호도와 작업 스타일을 저장합니다.  
- 여러 프로젝트에서 공통으로 참고되는 장기 기억 공간입니다.

## 모드 설명
### 일반 모드  
- 사용자가 제안된 코드 변경을 수동으로 검토·적용하는 기본 모드입니다.  
- 안전성과 통제를 중시할 때 사용합니다.

### 자동 수정 모드 (`auto-accept edit`)  
- Claude가 제안한 파일 편집을 자동으로 적용합니다.  
- 반복적인 수정·포맷팅 작업에 유용하지만, Git diff를 자주 확인하는 것이 좋습니다.

### 플랜 모드 (Plan 모드)  
- 직접 코드를 고치기보다, 우선 작업 계획·체크리스트를 상세히 작성합니다.  
- 큰 리팩터링·기능 개발 전에 요구사항과 단계별 계획을 정리할 때 사용합니다.

## 커스텀 슬래시 커맨드 추가 방법

- 사용자 전역 커스텀 명령은 `~/.claude/commands` 디렉터리에 추가합니다.  
- 이 디렉터리에 새 파일을 만들고, 파일 이름이 슬래시 명령 이름이 됩니다(예: `my-review.cmd`).  
- 파일 내용 안에 해당 명령이 수행할 프롬프트/지침을 자연어로 작성하면, `/my-review`처럼 호출할 수 있습니다.

## MCP 추가 방법

- 프로젝트 루트에 `.mcp.json` 파일을 생성하여 MCP 서버를 정의합니다.  
- 예시:

```json
{
  "servers": [
    {
      "name": "local-tools",
      "url": "http://localhost:8080"
    }
  ]
}
```

- Claude Code는 이 설정을 읽어 MCP 서버를 도구로 연결하고, 코드 편집 중 해당 도구를 호출할 수 있게 합니다.

## PRD와 실행 계획 문서 개념

- PRD(Product Requirements Document)는 기능의 목적, 배경, 요구사항, 제약 조건을 정리한 문서입니다.  
- 실행 계획 문서는 해당 기능을 구현하기 위한 단계별 작업 목록과 일정, 담당을 정리한 체크리스트입니다.  
- claude-code와 함께 작업 시작 전에 이 둘을 준비하면, AI에게 더 명확한 맥락을 제공하여 계획·코드 품질을 크게 높일 수 있습니다.

---

## 병렬 실행 / 직렬 실행 설명

- 병렬 실행은 여러 작업이나 테스트를 동시에 돌리는 방식으로, 독립적인 작업을 빠르게 처리할 때 유용합니다.  
- 직렬 실행은 작업을 순서대로 하나씩 처리하여, 의존성이 있는 단계나 디버깅이 필요한 상황에 적합합니다.  
- 큰 작업에서는 상위 계획만 직렬로 세우고, 실제 테스트·빌드·포맷팅 등 독립적인 서브태스크는 병렬로 돌리는 전략이 효율적입니다.

---

## 에이전트(agent) 추가 방법

- 에이전트는 특정 역할과 도메인(예: 테스트 전문가, 성능 튜너)에 특화된 AI 프로필입니다.  
- 설정 파일(예: `~/.claude/agents.json`) 또는 플러그인 UI에서 새 agent를 정의하고, 이름·역할·선호하는 작업 범위를 지정합니다.  
- 이후 Claude 패널에서 원하는 에이전트를 선택해, "테스트 전담", "리뷰 전담" 등 역할에 맞는 보조를 받으며 협업할 수 있습니다.
